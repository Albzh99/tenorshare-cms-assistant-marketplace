# 本站文章 HTML 规范

> 这是一份填写模板，不是通用 HTML。建立规范时复制到该站点 profile 目录的 `html-contract.md`，用本站已发布文章的真实片段替换所有占位项。某模块确实不存在时写“无（证据：……）”，不能留空，也不能复制其他站点的 class、CSS、尺寸、链接或产品信息。

## 适用范围与证据

- CMS 站点 ID／网址／语言／HTML 版式族（不是 CMS 分类）：【未填写】
- 规范版本与运营确认：【未填写】
- 参考文章：页面 ID、URL、模板 ID、`page/info` 文件及 SHA256：【未填写】
- 参考之间的差异、为何归为同一版式族；若跨分类取样，说明分类变化有没有改变正文 HTML：【未填写】
- 每条以下规则标注：`固定`／`可选`／`无`／`待确认`，写明出现条件、位置、相对顺序，并给出参考页 ID、文件位置和对应片段。`待确认` 的关键规则不能让 profile 变为 `ready`。这些栏目是观察清单，不表示本站必须有下载、指南、购买区或视频。

- H1、Meta Title、Description、关键词、主要关键词、URL 六项的本站写法与约束：【未填写】
- 分类是逐篇 CMS 元数据，不决定本规范的 H2／图片／Buy Box 等样式。记录已核对分类的名称、目录／URL、`classify_id`／`classify_page_id` 示例和证据；写明新稿如何按主题＋URL 实时查询并匹配，以及真正歧义时才请运营选择。无需穷尽本站所有分类：【未填写】
- 作者、产品、模块、相关文章如何实时查询并关联；哪些 ID 可固定、哪些每篇动态查：【未填写】
